# BillingBlock

The footer's credits: condensed, centred, three sizes of the same voice, plain facts only.

- `.s` small labels (Design & development, Built with, Robot model by) — 13px, tracked +14%.
- `.n` values and lists — 22px semibold.
- `.N` the leads (Ettore Serra, ROB-092) — 32px, `text-primary`.
- Everything else `text-secondary`. Max width ~980px, centred on the grid.
- **Copy says things as they are:** no "presents", "starring", "production" or rating jokes. The poster typography carries the atmosphere.
