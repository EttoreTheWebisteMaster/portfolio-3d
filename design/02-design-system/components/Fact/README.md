# Fact

A data column for a project's title block: a small label over a big value (Role, Stack, Year, Status).

- **Provide:** `<div class="es-meter"><span class="es-meter-label">Year</span><span class="es-meter-value">2026</span></div>`, three or four side by side with `space-7` gaps.
- Label `label-s` in `text-tertiary`; value `poster-m` in `text-primary`, tabular figures.
- **Only real facts.** No invented metrics (no match %, scores or meters). Replaces the retired MatchMeter.
