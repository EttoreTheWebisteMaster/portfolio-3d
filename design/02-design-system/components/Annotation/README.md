# Annotation

A handwritten Caveat note with a hand-drawn arrow pointing at the thing to try.

- Currently used once, on the loading page ("best with sound on"). The hero has no note.
- **One per screen, six words max.** Lowercase, no full stop (an exclamation is allowed).
- `text-note`: orange on dark, red on paper.
- Draw the arrow as an inline SVG path, round caps, 2.25px — wobbly, not geometric. Point at the subject, never at text.
- **Never** for body copy, quotes, the email or anything that must be read accurately.
