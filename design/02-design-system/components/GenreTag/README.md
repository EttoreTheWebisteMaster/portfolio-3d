# GenreTag

A small outlined label naming a project's discipline, used in the Projects index rows.

- Alumni Sans `label-s`, `text-secondary`, 1px `hairline-strong` outline, `radius-ui`.
- Needs `text-secondary` or brighter: the dimmer version failed contrast.
- One tag per row. Genres: Frontend, 3D, AI, Native, Voice UI, Research.
- Never filled, never coloured per genre.
