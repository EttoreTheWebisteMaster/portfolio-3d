# EpisodeRow

One chapter of a case study, listed like a TV episode.

- **Provide:** number, still (16:7), title, a two-line description, length.
- Current episode: `bg-raised` and the number lit `yellow`. Others: number in `text-tertiary` (never smoke-on-black), description in `text-secondary`.
- Clicking scrolls to that chapter; the current row follows the scroll.
