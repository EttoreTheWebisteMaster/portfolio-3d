# Logo

The name, set as type. No icon, no mark: it sits in the same family as the nav.

- **ETTORE SERRA** in Alumni Sans, 16px (14px on mobile), uppercase, tracked +24%, the two words half an em apart.
- **Two weights:** ETTORE in 800 `cream`, SERRA in 600 `#8C8576` (the nav's resting colour). The contrast is the only detail.
- **Hover:** SERRA brightens to `cream` (260ms, `cubic-bezier(.2,.7,0,1)`); nothing moves.
- **Provide:** `<a class="rob-logo" href="/" aria-label="Ettore Serra, home"><span>Ettore</span><span class="last">Serra</span></a>`.
- Top-left of every page, the loading page included. The marquee gold and Tac One stay with the hero's big name, never the logo.
